# **App Name**: PromptPilot

## Core Features:

- Task Input: Allow users to describe their task in plain language without requiring prompt engineering skills.
- AI Routing & Prompt Optimization: Utilize an AI tool (e.g., Gemini API) to analyze the user's task, select the most suitable target AI, and generate an optimized prompt for it.
- One-Click AI Access: Automatically copy the generated prompt to the clipboard and open the selected target AI's website in a new tab for seamless user flow.
- Prompt Refinement Loop: Enable users to provide feedback on the AI's output or describe what went wrong, and an AI tool will iteratively refine the prompt based on that feedback.
- Task History & Reuse: Maintain a history of all past user tasks and the generated prompts, allowing for easy review and one-tap reuse of any previous prompt.

## Style Guidelines:

- A light color scheme to convey clarity and efficiency, appropriate for a sophisticated utility app.
- Primary color: A muted yet assertive blue (#336699) to signify intelligence, stability, and trust, ideal for key interactive elements.
- Background color: A very subtle, cool-toned light grey (#ECF1F5) providing a clean and understated canvas for content.
- Accent color: A vibrant cyan (#39BBE6) for call-to-action buttons and important highlights, drawing attention effectively while complementing the primary blue.
- The primary font for both headlines and body text is 'Inter' (sans-serif), chosen for its modern, clear, and objective aesthetic, ensuring high readability and a clean interface.
- Use clear, concise vector icons that are minimalist and align with modern UI principles, ensuring instant recognition of functionality.
- Employ a clean, spacious layout with ample white space to enhance readability and guide the user's focus, reflecting an organized and efficient tool.
